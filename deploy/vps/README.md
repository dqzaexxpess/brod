# Свой сервер (VPS)

`install-xray-reality.sh` — установка VLESS + Reality (Xray) одной командой на свежем VPS (Debian/Ubuntu, root). В конце скрипт печатает ссылку `vless://…`:
вставьте её в приложении (Настройки → Мои серверы → Сервер). Свой сервер закрепляется и всегда стоит наверху списка узлов; пинг, скорость,
страна и чистота IP замеряются теми же кнопками.

Скрипт не проверялся на вашем сервере: прочитайте его перед запуском и запускайте на чистом VPS.
Повторный запуск безопасен (те же ключи, ссылка печатается заново). Порт по умолчанию 443/tcp (`PORT=… sudo bash …` меняет), маскировка под сайт
`www.microsoft.com` (`SNI=… sudo bash …`).

**Цепочка «клиент → ваш VPS → WARP»:** `sudo bash install-xray-reality.sh --warp` — на VPS регистрируется отдельный бесплатный аккаунт WARP (как у wgcf), весь выход идёт через Xray-outbound WireGuard на Cloudflare; сайты видят адрес Cloudflare, а не адрес датацентра. Эта часть, как и весь скрипт, не проверялась на настоящем сервере: после появления сервера её надо проверить на месте (`curl https://www.cloudflare.com/cdn-cgi/trace` через узел должен показать `warp=on`).
