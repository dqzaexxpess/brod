# Политика подписи кода

Бесплатная подпись кода: SignPath.io, сертификат SignPath Foundation (Free code signing provided by SignPath.io, certificate by SignPath Foundation).

Политика описывает, что и как подписывается в проекте Brod. Она относится только к файлам для Windows, которые собираются в этом репозитории.

## Что подписывается
- `brod-<версия>-windows-amd64-setup.exe` — установщик Windows;
- файлы внутри архива сборки и установщика: `Brod.exe`, `brodd.exe`, `brodctl.exe`.

Сторонние файлы (`wintun.dll` от WireGuard LLC, библиотеки Flutter и системные библиотеки) подписываются их авторами и здесь не переподписываются.

Подпись APK для Android — отдельная: постоянным ключом проекта (ключ хранится у автора и в защищённом окружении `release` GitHub Actions, где каждое использование подтверждается вручную). Обновления из приложения дополнительно проверяются подписью ed25519, открытая часть которой вшита в программу.

## Как собираются подписываемые файлы
Файлы собираются из исходников этого репозитория в GitHub Actions (`.github/workflows/build.yml`) без ручных шагов. После подключения SignPath запрос на подпись будет отправляться из этого же запуска (артефакт сборки передаётся в SignPath), подписанный результат попадает в релиз на GitHub. Исходники и сборочные скрипты публичны, лицензия — GPL-3.0.

## Роли
- **Автор и коммиттер:** владелец репозитория ([dqzaexxpess](https://github.com/dqzaexxpess)).
- **Проверяющий (reviewer):** владелец репозитория.
- **Утверждающий (approver):** владелец репозитория; каждый запрос на подпись утверждается вручную в SignPath.

Все участники используют многофакторную аутентификацию на GitHub и в SignPath.

## Политика конфиденциальности
Программа не отправляет данные пользователя разработчику и не содержит аналитики. Сетевые обращения делаются только по действиям и настройкам пользователя:
- загрузка подписок и источников узлов, которые добавил пользователь или которые включены в приложении по умолчанию;
- проверка узлов через сами узлы;
- проверка обновлений: раз в сутки загружается подписанный файл `releases.json` с GitHub, jsDelivr или GitLab; отключается настройкой `update.check`;
- запросы через выбранный пользователем узел к сайтам проверки (Cloudflare, Google, YouTube) для определения страны, чистоты адреса и доступности.
